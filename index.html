About Localhost AI

Vanilla HTML5, CSS3, and JavaScript running 100% in your browser.

This application makes direct browser-to-API requests via standard fetch() with Server-Sent Events (SSE) streaming support. There is zero server backend; all conversations, keys, and settings are saved locally in your browser's localStorage.

CORS Notice: Your configured endpoint must return Access-Control-Allow-Origin headers for direct browser requests (e.g. OpenRouter, Cloudflare AI Gateway, or local Ollama started with OLLAMA_ORIGINS="*").
